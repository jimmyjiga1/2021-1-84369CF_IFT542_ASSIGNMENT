# Ethics and Authorised-Testing Statement

I confirm that all security testing performed for this assignment (IFT542 Practical Assignment
— Security Assessment and Hardening of a Student Registration Web Application) was conducted
under the following conditions:

1. All testing was performed exclusively against a local instance of the application running on
   `localhost`, under my own control.
2. No FUT Minna production system, public website, or third-party service was scanned, probed,
   or tested at any point.
3. Only fictitious data (dummy names, matric numbers, emails, and passwords) was used throughout
   development, seeding, and testing — no real student or staff data was entered into the
   application or its database.
4. No reusable attack payload, exploit script, or automated attack tool was submitted as part of
   this assignment's evidence; vulnerabilities are demonstrated only through the specific,
   contained test cases described in `tests/run_tests.php` and `evidence/before_after/`.
5. All secrets (database passwords, session tokens) present in the evidence folder have been
   removed or replaced with placeholder values before submission.
6. This work was undertaken solely for the educational purpose of this assignment, in line with
   FUT Minna's academic integrity policy and the assignment's authorised-lab restriction.
